# SAÉ 4.Cyber.01 · Sécuriser un système d’information

> Déploiement d’une infrastructure de laboratoire sécurisée avec pare-feu Stormshield, DMZ, services chiffrés, détection d’intrusions et tests d’attaque.

| | |
|---|---|
| **Formation** | BUT Réseaux et Télécommunications, Montbéliard |
| **Année** | 2<sup>e</sup> année, semestre 4, parcours cybersécurité |
| **Organisation** | En équipe de 4, sur deux semaines |
| **Outils et notions** | `Stormshield` `NAT` `Filtrage` `DMZ` `HTTPS` `FTPS` `Certificats SSL` `SSO` `Snort` `Scanners de vulnérabilités` `MITM` |

## Infrastructure

Chaque équipe disposait de deux pare-feu Stormshield, d’un switch, d’une borne Wi-Fi et de cinq postes, pour construire une architecture **LAN / DMZ / WAN**.

## Tâches et état de réalisation

| # | Tâche | État |
|---|---|---|
| 1 | Mise en place d’une infrastructure sécurisée | Documenté |
| 2 | Installation et configuration du pare-feu Stormshield (NAT, filtrage, tests d’accès) | Documenté |
| 3 | Serveurs HTTP/HTTPS et FTP/FTPS | Documenté |
| 4 | Authentification transparente par certificat SSL | Documenté |
| 5 | Détection d’intrusions avec Snort | Documenté |
| 6 | Attaque sur le Wi-Fi | Documenté (laboratoire) |
| 7 | Scanners de vulnérabilités | Documenté |
| 8 | Attaque Man-in-the-Middle | Documenté (laboratoire) |
| 9 | Contre-mesures contre le MITM | Documenté |
| 10 | Supervision du réseau | Partiel |
| 11 | Architecture Single Sign-On | Étude |
| 12 | VPN SSL pour clients distants | Partiel, sans compte rendu |
| 13 | VPN IPsec site à site | Partiel, sans compte rendu |

Le cahier conserve les configurations, les captures et les essais, y compris ceux qui n’ont pas abouti.
